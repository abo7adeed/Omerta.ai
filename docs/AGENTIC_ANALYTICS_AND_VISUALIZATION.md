# Omerta.ai — Deterministic Analytics & Matplotlib Visualization Engine

## 1. Deterministic Financial Analytics

Financial calculations must never be generated by free-form LLM arithmetic. Omerta.ai implements `DeterministicAnalyticsService` (`domain/agentic_rag/analytics.py`) to execute pure Python mathematical operations:

### 1.1 Metrics Supported
- **Counts and Sums:** Absolute transaction counts and aggregated currency volumes.
- **Descriptive Statistics:** Mean, median, minimum, maximum, standard deviation, and quantiles (P25, P75, P90, P99).
- **Time-Bucket Aggregations:** Grouping transactions by hour, day, week, or month.
- **Outlier Detection:** Z-score thresholding (`abs(z) > 2.5`) with strict sample size validation (`n >= 5`).

### 1.2 Safe Percentage Change Formula
When comparing periods:

$$\text{Percentage Change} = \frac{\text{Current} - \text{Previous}}{\text{Previous}} \times 100$$

If $\text{Previous} == 0$, division by zero is strictly avoided:
- If $\text{Current} > 0$, `percentage_change = None`, display label: `+N/A (from zero)`.
- If $\text{Current} == 0$, `percentage_change = 0.0`, display label: `0.0% (no activity)`.

## 2. Dynamic Matplotlib Visualization Engine

The backend visualization service (`domain/agentic_rag/visualization.py`) renders publication-quality charts styled according to Omerta.ai's Premium Corporate theme:

### 2.1 Palette and Corporate Aesthetic
- **Omerta Sapphire:** `#002D72` (Primary series, axis titles)
- **Omerta Gold:** `#F9A825` (Secondary series, accents, highlights)
- **Emerald:** `#10B981` (Inflows, positive trends)
- **Royal Blue:** `#1E88E5` (Neutral series, comparison baselines)
- **Crimson:** `#D32F2F` (Outflows, high-risk bars)
- **Background:** Clean pure white (`#FFFFFF`) with subtle gridlines (`#E2E8F0`).

### 2.2 Supported Visualizations
1. **Line Charts:** Historical volume trends, daily velocity, balance trajectories.
2. **Bar Charts:** Categorical volume comparisons, status breakdowns.
3. **Horizontal Bar Charts:** Ranked counterparty accounts or merchants.
4. **Histograms:** Transaction amount frequency distributions.
5. **Scatter Plots:** Amount vs risk-score correlations.
6. **Donut Charts:** Currency shares, risk tier distributions.
7. **Heatmaps:** Hour-of-day vs day-of-week transaction density matrices.

## 3. Frontend Inline Rendering

In `frontend/src/pages/AiAssistantPage.tsx`, chart blocks are parsed from the response stream and rendered directly in the conversation timeline:
- High-resolution preview with loading skeleton.
- Expandable citation links underneath each chart.
- Click-to-zoom interactive modal supporting full-resolution inspection.
